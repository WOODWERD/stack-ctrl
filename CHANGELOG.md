# Changelog

What changed in each version of [Stack Ctrl](https://woodwerd.github.io/stack-ctrl/), newest first. Versions are x-numbers while Stack Ctrl is a public beta.

## x0.0.2 · 2026-11-03
- A box ID after the # in the link fills the search, so Tool Ctrl's See in Stack Ctrl opens with that box found.

## x0.0.1 · 2026-11-02
- Your Systainers from Tool Ctrl, drawn from the front to scale. Drag them into stacks on the floor or on a cart, and each stack shows its height in mm and inches.
- It won't stack boxes that don't latch, such as a Classic on a newer box, and says why. L and M boxes latch either way.
- Slide a box under the bottom of a floor stack to lift the stack onto it.
- Moves go back to Tool Ctrl as where each box sits, and show there live.
- Public beta at woodwerd.github.io/stack-ctrl.
