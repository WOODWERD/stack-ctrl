# Stack Ctrl

Your Systainers, drawn to scale and stacked. Stack Ctrl reads the boxes you record in [Tool Ctrl](https://woodwerd.github.io/tool-ctrl/), draws each one from the front at its real size, and lets you drag them into stacks on a floor or a cart. Each stack shows its height in mm and inches.

Part of the WOODWERD Toolkit. Status: x0.0.1, local build, not yet published.

- Systainers only: TANOS and Festool Systainer³, T-Loc and Classic boxes, their Sortainers, and carts.
- Every box, number, name and model comes from Tool Ctrl. Stack Ctrl changes only where each box sits.
- It runs in your browser and shares Tool Ctrl's record on the same device. Tool Ctrl's GitHub sync carries it to other devices.
- Arrange on a computer or iPad. A phone is look-only.
